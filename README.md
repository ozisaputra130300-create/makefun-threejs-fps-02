Emberline: a round-based tactical FPS in the Kestrel Works foundry yard. One striker against four Warden bots — plant the spike at the Furnace or the Silos, or drop every defender. First to 5 rounds takes the yard. Built on three.js 0.187.0, no build step, no network: static files under `game/`, bots with patrol/investigate/engage/defuse AI, an economy with a buy menu, four guns and a frag grenade, and gunplay where stopping to aim pays.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
